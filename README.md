# 坦克大战 Tank Battle

经典红白机（Battle City）风格的 HTML5 坦克大战，纯原生 JavaScript + Canvas 实现，**零依赖、零构建**，打开网页即玩。

🎮 **在线试玩：<https://conanmlb.github.io/tank-battle/>**

---

## 特性

- **经典玩法**：13×13 战场，保护己方老巢 🦅，消灭全部敌方坦克过关
- **半格砖墙破坏**：砖墙以 16px 小格为单位被摧毁，打出与街机原作一致的正齐缺口
- **6 种道具**（击毁闪烁敌人掉落）：

  | 道具 | 效果 |
  | --- | --- |
  | ⭐ 星标 | 升级主炮：子弹加速 → 双发 → 可击穿钢墙（死亡重置） |
  | 💣 手雷 | 立即炸毁屏幕上所有敌人 |
  | 🪖 头盔 | 10 秒无敌护盾 |
  | 🛠 铲子 | 15 秒内老巢围墙变为钢墙（最后 3 秒闪烁提示） |
  | 🕐 时钟 | 冻结所有敌人 8 秒 |
  | 🚙 坦克 | 生命 +1 |

- **4 种敌方坦克**：普通 / 快速 / 炮击（快弹）/ 装甲（4 点血、按血量变色）
- **智能 AI**：敌人会追踪老巢与玩家、卡住时自动换路、对准目标时优先开火
- **3 个关卡**：不同地形（砖墙 / 钢墙 / 河流 / 树丛）与敌人配置，逐关递进
- **完整系统**：生命 / 计分 / 最高分（localStorage 持久化）/ 暂停 / 静音
- **WebAudio 音效**：全部程序合成，无外部资源
- **触屏支持**：移动端自动显示虚拟方向键与开炮键
- **响应式布局**：画布自适应窗口，附带复古扫描线滤镜

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / `↑` `↓` `←` `→` | 移动 |
| `空格` / `J` | 开炮 |
| `Enter` | 开始 / 继续 |
| `P` / `Esc` | 暂停 |
| `M` | 静音开关 |

> 手机 / 平板：使用屏幕下方的虚拟方向键与红色"发射"按钮。

## 本地运行

无需安装任何依赖：

```bash
# 方式一：直接双击 index.html，或
# 方式二：起一个本地静态服务器（推荐，音效策略更宽松）
python -m http.server 8000
# 然后访问 http://localhost:8000
```

小技巧：URL 追加 `#play` 可跳过标题页直接开打，例如
`index.html#play`（方便嵌入 iframe 或演示）。

## 技术实现

- **Canvas 2D**，逻辑分辨率 416×416，2× 渲染缩放，矢量绘制全部精灵（无图片资源）
- **静态层烘焙**：砖墙 / 钢墙离屏预渲染，仅在场景变化时重建，保证流畅度
- **地形网格** 26×26 小格，坦克占 2×2 小格；转向时自动对齐 16px 网格（经典手感关键）
- **子弹判定矩形**在垂直方向扩展至坦克宽度，复原原作"打出坦克宽缺口"的细节
- 固定对象池 + 帧内子步进碰撞检测，避免高速子弹穿透
